## 0. 已确认的 P0 范围

| # | 功能决策 | V1.0 基线 | 影响 |
|---:|---|---|---|
| 1 | 首期场景与命名 | 用户界面统一使用“会议”；当前仅展示“售前商务会议”模板 | 面试模板后置；历史类型仅用于本地数据兼容，不在用户侧显示 |
| 2 | 高级会议字段 | 采用推荐默认值：参会者角色、会议目标、禁答边界均后置 P1 | P0 表单、数据模型和迁移保持最小集 |
| 3 | 材料处理 | 售前资料由用户勾选后进入本次回答上下文 | 保留清晰的来源、删除和资料范围控制；简历相关流程随面试模板后置 |
| 4 | 云端复盘 | 0.4 只开发前端界面、状态与信息架构；不接入后端，不上传转写 | 不创建 ReviewReport 生成任务、云端 API 或伪造复盘数据 |
| 5 | 导出范围 | P0 仅 Markdown 导出 | PDF/DOCX 与外部推送后置 P1 |
| 6 | 提醒触发 | 默认候选预检索 + 用户确认 | 预检索不等于自动生成或自动展示可说答案 |
| 7 | 会中展示 | P0 使用主客户端中央答案区 | 悬浮窗后置 P1 |
| 8 | 产品边界 | 不自动发言、发送或对外行动；不分析他人人格或情绪 | 生成契约、页面文案和复盘 UI 必须共同遵守 |

## 1. 当前基线与目标差距

| 领域 | 当前基础 | V1 目标增量 |
|---|---|---|
| 前端 | 工作区、知识库、回答风格、实时三栏、记录、可观测性 | 统一“会议”术语、售前 Meeting Packet、Session、复盘前端页、全量状态 |
| Rust | 手工问题 RAG、流式回答、Keychain、导入、本地检索 | Orchestrator、范围过滤、Session/Turn/Suggestion/Trace 实体 |
| Swift | 系统音频与麦克风双源采集桥接 | 收帧健康、设备变更、重连、会话采集状态 |
| 云端 | ASR、OCR、Embedding、Rerank、Chat 适配器 | 实时受控检索与生成；复盘云端后端明确后置 P1 |

## 2. 开发阶段

### 0.2 会前上下文与 Meeting Packet

| 项 | 内容 |
|---|---|
| 用户价值 | 将分散的会议信息和资料范围变成可复用、可审计的上下文 |
| 前端 | “新建会议”、售前商务会议模板、背景/客户/备注/会议要求、资料范围 |
| Rust/数据 | `MeetingPacket`、版本快照、范围过滤、用户可控保留/删除 |
| 云端 | OCR/VLM 或文本解析输出结构化 JSON，Schema 校验 |
| 验收 | 可保存/复制/编辑；检索不越过本次范围；页面不显示面试、简历或岗位 JD 模板 |
| 主要风险 | 扫描 PDF OCR 质量与成本；跨客户资料误用 |
| MVP | 是 |

### 0.3 实时会议提醒闭环

| 项 | 内容 |
|---|---|
| 用户价值 | 会议中快速得到可引用、可说、可确认的建议 |
| 前端 | 音频健康、实时语境、中央答案、候选确认、15/60 秒、暂停/重答/复制 |
| Rust/数据 | `MeetingSession`、`TranscriptTurn`、`QuestionCandidate`、`Suggestion`、`MeetingOrchestrator`、事件协议 |
| Swift | 双音源帧数、采样率、设备变更与无帧诊断 |
| 云端 | ASR、Embedding、Rerank、流式 Chat；超时/错误策略 |
| 验收 | 50 条中英/业务问题压测；P95 首字 ≤ 3 秒；回答均有依据/待确认状态 |
| 主要风险 | 真实设备音频路由、ASR 鉴权/协议、网络抖动、模型时延 |
| MVP | 是；作为继续扩展的质量门槛 |

### 0.4 云端复盘前端界面（不含后端）

| 项 | 内容 |
|---|---|
| 用户价值 | 提前验证复盘信息架构、授权提示和用户查看路径，不把未实现能力包装为可用服务 |
| 前端 | 复盘入口、摘要/问题账本/回答与证据/关注点/行动项页签、空态、待接入态、Markdown 导出禁用态及删除入口 |
| Rust/数据 | 不新增云端复盘任务、报告持久化或服务端调用；可选仅保留本地导航状态 |
| 云端 | 不调用任何复盘模型，不上传转写、引用或知识库材料 |
| 验收 | 页面可进入；无会话/无网/未接入均有明确状态；页面不展示伪造评分、结论或生成时间；网络面板/Trace 无复盘云端请求 |
| 主要风险 | 用户误认为报告已生成；必须以“功能待接入”与禁用操作明确区分 |
| MVP | 是，限前端界面验证 |

### P1 云端复盘后端闭环

| 项 | 内容 |
|---|---|
| 用户价值 | 经用户授权后，将已保留会话转为证据可回溯的摘要、问题账本、待办和练习 |
| 主要交付 | `ReviewReport`、`ActionItem`、授权记录、受控任务图、证据校验、Markdown 导出和删除联动 |
| 主要风险 | 长会话上下文成本、报告幻觉、数据上传范围、地区/平台政策 |
| 进入条件 | 复盘前端走查通过；用户授权模型、云端数据流、成本上限、证据门控和合规审查另行确认 |
| MVP | 否 |

### P2 训练与扩展

| 项 | 内容 |
|---|---|
| 用户价值 | 将复盘转化为模拟练习、追问和长期提升 |
| 内容 | 模拟演练、追问树、基于资料的题库、多语言、趋势报告、悬浮窗 |
| 主要风险 | 产品范围膨胀、真实会议与训练数据混淆、非可解释评分 |
| MVP | 否 |

## 3. 工作包与完成定义

| 工作包 | 依赖 | Definition of Done |
|---|---|---|
| 数据迁移 | P0 #1-#3 | 新增实体可迁移、删除；单元测试覆盖版本快照和范围隔离 |
| Packet/资料范围 | 数据迁移、文件导入 | 未勾选资料不得进入生成；失败状态可见、可重试、可删除 |
| Orchestrator | Packet、音频诊断 | 状态机与事件含 ID；固定工具预算；故障不终止整个 Session |
| 实时 UX | Orchestrator | 中央答案、引用、待确认、用户控制与全异常状态可测试 |
| 复盘前端 | Session 导航 | 只呈现未接入产品态；无报告生成、无伪造结果、无云端复盘请求 |
| 可观测性 | 全链路 | 音频、ASR、检索、重排、生成可关联；无密钥与正文泄漏 |
| 性能/安全验收 | 实时工作包 | 50 条测试集、弱网/无权限/无命中/超时、删除验证、日志审查通过 |

## 4. 关键测试矩阵

| 类别 | 必测场景 |
|---|---|
| 权限/采集 | 缺屏幕录制、缺麦克风、只有单音源、无帧、设备切换、开始/暂停/停止 |
| ASR | 鉴权失败、15 秒无数据、部分结果、中英文、系统音频/麦克风来源 |
| RAG | 资料范围隔离、无命中、Embedding 失败、Rerank 失败、引用回溯 |
| 生成 | 流式部分返回、超时、重试、待确认输出、禁止自动发送 |
| 复盘前端 | 无会话、服务待接入、无网、Markdown 导出禁用、删除入口、无云端请求 |
| 安全 | Keychain 遮罩、日志无密钥/正文、资料范围控制、文档提示注入不改变策略 |

## 5. 发布门禁

1. 0.2 和 0.3 的所有 P0 验收标准通过；0.4 仅按“前端未接入态”验收。
2. 真实音频帧与 ASR 字符均可在 UI 和 Trace 验证。
3. 指定网络/模型/测试集下，问题结束至首个可读建议 P95 ≤ 3 秒；未达标则继续优化而不对外承诺。
4. 引用/待确认策略抽样审查通过；无依据内容不被包装为事实。
5. 删除、Markdown 导出、密钥与日志安全审查通过。
6. macOS 权限、云服务数据地域、会议录音提示和平台政策完成上线前合规确认。

## 6. 交付节奏

```text
0.2 Packet/资料范围 → 0.3 实时提醒/性能门禁
                         → 0.4 云端复盘前端（无后端、无上传）
                         → P1 专项确认 → 云端复盘后端闭环 → 训练与扩展
```

本版本不承诺上线日期，不将 3 秒目标描述为已实现性能，也不把复盘界面描述为已具备云端复盘能力。
